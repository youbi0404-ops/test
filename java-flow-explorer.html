Java 프로젝트 폴더를 선택하세요

폴더를 이 영역에 끌어다 놓거나 아래 버튼으로 선택하면 바로 분석합니다.

  • 모든 분석은 이 브라우저 안에서만 수행됩니다. 네트워크 통신이 전혀 없으며 소스가 PC 밖으로 나가지 않습니다.
  • 브라우저가 "파일 N개를 업로드하시겠습니까?"라고 묻는 것은 로컬 파일 읽기 허용 확인이며 실제 전송은 없습니다.
  • 메서드·클래스 위의 주석(Javadoc)과 본문 주석, SQL XML 주석을 흐름에 함께 표시하고 주석 내용으로도 검색됩니다.
  • "소스 검색"으로 모든 소스에서 문자열을 찾고, 그 줄이 어느 화면(URL)에서 어떤 경로로 실행되는지 확인할 수 있습니다.
  • .java / .xml 파일을 읽어 URL → Controller → Service → DAO → SQL → 테이블 흐름을 구성합니다.
  • Spring XML 빈 설정, Anyframe Query 매핑, iBATIS/MyBatis SQL 맵, Struts 설정, 소스 내 인라인 SQL을 인식합니다.
흐름에서 항목을 클릭하면 소스와 SQL이 여기에 표시됩니다.
